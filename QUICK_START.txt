🚀 FASTEST START (Recommended)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. Make sure Ollama is running:
     $ ollama serve

     (Open in a NEW terminal tab)

  2. In project directory, run:
     $ ./run.sh

  3. Open browser:
     http://localhost:8501

  $ streamlit run app.py


INSTALL MODELS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  $ ollama pull deepseek-coder:1.3b    (Default - Fast, Good for code)
  $ ollama pull llama2                 (Balanced, Good for general chat)
  $ ollama pull mistral                (Very fast)
  $ ollama pull neural-chat            (Optimized for conversation)

  List installed models:
  $ ollama list

SETTINGS (Left Sidebar)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  📋 Chats
    • Create new chat
    • Switch between conversations
    • Recent chats appear first

  ⚙️  Settings
    • Model: Select from installed Ollama models
    • Temperature: 0-1.0 (lower = more consistent)
    • Max tokens: Output length
    • System prompt: Customize AI behavior

  🔧 Advanced
    • Context turns: How many previous messages to consider
    • Stream output: Real-time response streaming
